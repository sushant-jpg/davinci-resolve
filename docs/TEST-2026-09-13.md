## Try it locally

From the repository directory:

```sh
./scripts/run.sh build/manual-test/sample.sentinel
```

The sample has two clips and a one-second gap. Press Space to play. Select a clip, seek inside it and press S to split; try Ctrl+Z, dragging and trimming. Save with Ctrl+Shift+S to another `.sentinel` file and reopen it. Export with Ctrl+M to `build/manual-test/my-export.mp4` and play the result.

To run the existing automated binaries from a normal desktop terminal:

```sh
export PATH="$PWD/.local-deps/bin:$PATH"
export LD_LIBRARY_PATH="$PWD/.local-deps/lib${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"
./build/sentinel_tests
QT_QPA_PLATFORM=offscreen QT_QPA_PLATFORMTHEME=generic QT_STYLE_OVERRIDE=Fusion ./build/sentinel_ui_tests
```
